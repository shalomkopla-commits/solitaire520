# תיקיית מעקב תקלות ונושאים פתוחים - issues

תיקייה זו מיועדת לתיעוד באגים, תקלות, שאלות פתוחות וחסמים (Blockers) שהתגלו במהלך העבודה על ידי המשתמש או הסוכנים.

---

## מבנה קובץ תקלה
שם הקובץ: `ISSUE-<מספר>_<תיאור_קצר>.md` (לדוגמה: `ISSUE-001_cors-configuration-error.md`)

כל קובץ תקלה יכיל:
1. **סטטוס**: `Open` / `In Progress` / `Resolved`
2. **תאריך פתיחה**
3. **סוכן / משתמש מדווח**
4. **תיאור התקלה וצעדים לשחזור (Reproduction Steps)**
5. **השפעה מערכתית**
6. **פתרון מוצע או פתרון שבוצע בפועל**
