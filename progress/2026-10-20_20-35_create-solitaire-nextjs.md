# משימה: יצירת משחק סוליטייר (Klondike Solitaire) ב-Next.js

---

## 📋 שלב א': לפני המשימה (Pre-Task)
- **תאריך ושעת התחלה**: 2026-10-20 20:35:00 (IDT)
- **סוכן מבצע**: Antigravity (Gemini 3.8 Flash)
- **תיאור המשימה ובקשת המשתמש**:
  - פיתוח משחק סוליטייר מלא, אינטראקטיבי ומעוצב ברמה פרימיום באמצעות Next.js ("צור משחק סוליטייר בnextjs").
- **יעדים ותוכנית פעולה**:
  1. בדיקת סביבת Node.js ו-npm והתקנתם לפי הצורך (באמצעות winget).
  2. יצירת פרויקט Next.js מודרני מבוסס TypeScript ו-Vanilla CSS מעוצב ומלוטש (Green Felt Casino / Luxury Velvet look).
  3. מימוש מלא של חוקי משחק Klondike Solitaire:
     - חפיסת קלפים מלאה (52 קלפים, 4 סדרות, צבעים שחור/אדום, דרגות A עד K).
     - מאגר קלפים (Stock pile) ומאגר חשוף (Waste pile) עם אפשרות סבב חוזר.
     - 4 ערימות יעד (Foundation piles) - בנייה מאס למלך באותה הסדרה.
     - 7 טורים (Tableau piles) - בנייה לסירוגין בצבעים ובסדר יורד, עם חשיפת קלפים שהופכים עליונים.
     - תמיכה מלאה בגרירה והשלכה (Drag & Drop) וכן בלחיצה מהירה (Click to Auto-Move).
     - מנגנון ביטול מהלך (Undo), ספירת מהלכים, ניקוד (Score) ושעון זמן (Timer).
     - אפקטי ניצחון מרהיבים (חגיגת קלפים קופצים / זיקוקים בסיום).
  4. עיצוב פרימיום (CSS Design System):
     - רקע לבד קלאסי עשיר (Felt Green Gradient עם טקסטורה עדינה).
     - קלפים מעוצבים ויזואלית ברמת דיוק גבוהה, עם אנימציות תנועה וצללים ריאליסטיים.
     - התאמה רספונסיבית לכל גדלי המסכים.
  5. בדיקת תקינות, הרצת שרת פיתוח מקומי ואימות מלא.
  6. עדכון תיעוד המשימה (Post-Task) וסנכרון מול Git ו-GitHub.
