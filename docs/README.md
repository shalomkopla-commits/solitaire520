# תיקיית תיעוד - docs

תיקייה זו מרכזת את כל התיעוד המערכתי, המפרטים, והחלטות הארכיטקטורה של הפרויקט.

---

## מה נשמר כאן?
1. **מפרטים טכניים ואפיונים**: תיאור דרישות מערכת, מודלים של נתונים ו-Flows.
2. **החלטות ארכיטקטוניות (Architecture Decision Records - ADR)**:
   - כל החלטה עקרונית (בחירת ספרייה, מבנה מסדי נתונים, עיצוב API) מתועדת בקובץ נפרד.
   - פורמט: `ADR-001_<decision_title>.md`.
3. **מדריכים ותיעוד API**: הסברים על ממשקים ושירותים קיימים.
